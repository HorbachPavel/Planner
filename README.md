# FocusFlow

Локальный персональный таск-трекер для macOS. Интерфейс работает на
`localhost`, а задачи хранятся в SQLite только на ноутбуке.

## Возможности

- быстрый ввод задач сразу в статус «В план»;
- ручной порядок задач перетаскиванием;
- единый компактный экран без переходов между разделами;
- выбираемый срок: без срока, просрочено, сегодня, завтра, эта неделя, следующая неделя или позже;
- одна рекомендуемая задача в Focus-режиме;
- повторения и оценка времени;
- темы для разговора с людьми;
- отдельное поле для личных дел и идей;
- JSON backup/restore и журнал изменений.

Системные уведомления, мобильная версия и облачная синхронизация задач намеренно
не входят в MVP.

## Запуск

Требуются macOS, Node.js 22+ и npm.

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). Production-сборка:

```bash
npm run build
npm start
```

SQLite создаётся в:

```text
~/Library/Application Support/FocusFlow/assistant.sqlite
```

Для тестов или отдельного профиля путь можно заменить переменной
`ASSISTANT_DB_PATH`. Секреты сохраняются в macOS Keychain с именем сервиса
`FocusFlow Local Assistant`; они не попадают в SQLite, backup или git.

## Резервные копии

Пока приложение запущено, оно каждые 3 минуты проверяет задачи, темы для людей
и личный блокнот. Новый JSON-файл создаётся только при изменении данных.
Хранится не больше 200 копий. Секреты из Keychain в копии не попадают.

Если в OneDrive есть папка `Focus Flow BackUps`, копии сохраняются туда.
Приложение не создаёт ссылку общего доступа. Это рабочий OneDrive, поэтому
администратор организации тоже может иметь доступ к файлам. Если папка не
найдена, копии лежат локально в

```text
~/Library/Application Support/FocusFlow/backups
```

Свою папку можно задать переменной `ASSISTANT_BACKUP_DIR`.

## Резервные копии вручную

Кнопка «Скачать копию» экспортирует задачи, time blocks и несекретные
настройки. Восстановление:

```bash
curl -X POST \
  -H 'Content-Type: application/json' \
  --data-binary @focusflow-2026-10-19.json \
  http://localhost:3000/api/backup
```

Восстановление заменяет текущие задачи, блоки времени, людей и личный блокнот.
Сначала сохраните свежую копию.

## Проверка

```bash
npm test
npm run lint
npm run build
```

Тесты покрывают сроки, повторения, защиту от дублей, ручной порядок и CRUD.
Основной сценарий: записать задачу → выбрать срок → перетащить её на нужное
место → завершить и получить следующий экземпляр повторяющейся задачи.

## Локальные API

- `GET/POST /api/tasks`, `PATCH/DELETE /api/tasks/:id`, `POST /api/tasks/reorder`
- `GET/POST /api/calendar`, `DELETE /api/calendar/:id`
- `GET/POST /api/people`, `PATCH/DELETE /api/people/:id`
- `GET/PUT /api/scratchpad`
- `GET /api/outlook/auth`, `POST /api/outlook/sync`
- `POST /api/outlook/ics`
- `GET/POST /api/backup`

Все API слушают только тот адрес, с которым запущен Next.js. Скрипт `npm start`
явно привязывает production-сервер к `127.0.0.1`.
